# Laboratorio M7 de IAM y Hardening

Actividad individual ejecutada en GitHub Codespaces. El entorno contiene configuraciones inseguras intencionales para observar, analizar, corregir y verificar.

## Reglas

- Trabaja únicamente dentro de tu Codespace.
- No escanees sistemas externos.
- No pruebes credenciales contra terceros.
- Espera las instrucciones de la instructora antes de ejecutar cambios.

## Verificación inicial

```bash
bash ./lab/check-hardening.sh
```

En la primera ejecución deben aparecer varios resultados `FAIL`. Esto es parte del escenario.

## Entrega

Completa el archivo `evidencias/evidencia_m7.md` con tus observaciones, decisiones y verificaciones.
